# Multi-modal RAG

A retrieval-augmented Q&A system over a small dataset of world landmarks, supporting
text-to-image, image-to-text, and text-to-text retrieval, with answers grounded in
the retrieved context and generated by OPT-1.3B.

```text
query (text or image) -> CLIP / sentence-transformer retrieval -> OPT-1.3B answers using only the retrieved context
```

See [REPORT.md](REPORT.md) for the dataset, architecture, example results, and
discussion of limitations.

## Setup

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Build the dataset

```bash
python build_dataset.py
```

Downloads 14 landmark photos and matching text descriptions from Wikipedia into
`data/images/` and `data/metadata.csv` / `data/metadata.json`.

## Run the demo

```bash
python run_demo.py
```

Runs one query of each kind (text-to-image, image-to-text, text-to-text),
printing the retrieved items, their similarity scores, and the generated answer.

## Project layout

- `build_dataset.py` — assembles the image/text dataset from Wikipedia
- `embeddings.py` — CLIP and sentence-transformer encoding functions
- `vector_store.py` — FAISS indices and cross-modal retrieval functions
- `generation.py` — prompt construction and OPT-1.3B generation
- `run_demo.py` — end-to-end demo across all three query types
- `data/` — dataset images and metadata
- `REPORT.md` — dataset, architecture, results, and reflections
